# 少了一斗的粟 · 独立教学游戏

本章从 `law-mountains/index.html` 进入，也可直接打开本目录的 `index.html`。它不改动原有十案的案卷逻辑或存档。原先在工作区 `output/` 中的完整游戏、对话版样章和原始 PNG 美术均保留；本章使用独立的 WebP 美术副本。

公开游玩地址：<https://sabi678.github.io/tiying-law-game/law-mountains/shao-yidou/>。

## 游玩路径

孟庸告发 → 一次共同复量 → 任选雨路或集市的一条问话线 → 田禾问话 → 县吏记录 → 审案官吏要求说明依据 → A 草率重罚、B 审慎处理、C 定向补查或暂缓、D 只补损失 → 三位人物回应与可能的后续影响 → 六选三规则改进 → 春秋、战国、秦朝三个明确分开的制度复盘 → 教师底稿揭示。

早期选择会改变可取得的陈述、案卷的充分程度和是否能直接选择 B。C 允许一次有目标的补查；也可以保留疑点结束。没有按处罚轻重排名的分数。进度保存在本机浏览器；“重开”会清除本章进度。

## 史料和虚构边界

- 秦代卡片依据睡虎地秦简《法律答问》《封诊式》《语书》《为吏之道》等材料及课程教案。每张卡分列可核实史实、教学解释、虚构案情边界，并提供出处链接。
- 春秋郑国子产铸刑书和战国秦国商鞅变法只在结案后的独立复盘视角出现，不能作为秦朝虚构交易的直接法条。
- 不设本案秦律条号、刑名或刑度。人物、交易、问话和结局是教学创作；后果中的社会反应是可能性推演，不是历史统计。
- 教师底稿在游戏画面中仅于最后复盘揭示。静态网页的资源可被熟悉开发工具的人查看，因此这不是安全的教师权限系统；若要求技术层面的严格隔离，需另建有鉴权的服务。
