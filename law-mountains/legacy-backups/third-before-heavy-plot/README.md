# 第三卷《少了一斗的粟》

本卷是秦统一后某县的教学虚构互动叙事。直接打开 `index.html`，或从十案图第三卷进入。玩家扮演年轻县吏，以对话选择推动交易争执、一次共同复量、人物陈述、县署处理及后来市场中的报错和作证。人物立绘与背景复用原素材，人物信息不写入图片。

## 主要路径

- **拟请重处**：市口迅速安静，但田禾、阿叶和量粮人趋于谨慎。次日官吏明确把重处意见留作待核建议，不凭短少直接认定故意；双方另行核对并补足一斗。后来市场仍有报错顾虑。
- **先回应损失**：在完整记录和可核对陈述具备时，可促成双方核对并补足一斗；故意仍待查。买主的损失先有回应，但不等于卖主承认故意。
- **补记续查**：始终可选。次日双方再到县署，卷宗保留量粮人的原说与更正；处理损失因此延迟，但依据更清楚。

前四个对话选择影响公开初稿、田禾的雨路陈述、阿叶是否能说明所见边界，以及量粮人的更正是否进入卷宗。这些状态决定处理意见是否可选，并改变人物后续对白和数日后的市场行动。最终的市口说明会影响别人是否知道怎样更正错误。重处只是玩家的处理**建议**，不是已经实施的刑罚。

## 史实与虚构

秦代背景卡援引睡虎地秦简《法律答问》《封诊式》，用于讨论法律解释、讯问与记录，不用作本案的具体判例。春秋子产铸刑书与战国重刑思想只在明确标注年代的独立复盘中出现。县市、人物、粮食交易、重处风声、对话和处理经过均为教学虚构；游戏没有给本案编造秦律条文、刑名或刑度。
