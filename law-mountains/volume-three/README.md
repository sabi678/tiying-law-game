# 第三卷《少了一斗的粟》

本卷是秦统一后某县的教学虚构互动叙事。直接打开 `index.html`，或从十案图第三卷进入。玩家扮演年轻县吏，以对话选择推动交易争执、一次共同复量、人物陈述、县署处理及后来市场中的报错和作证。人物立绘与背景复用原素材，人物信息不写入图片。

## 主要路径

- **教学反事实重刑**：先在市口提出重刑主张，次日支持重刑裁断。由审案官吏作出裁断，田禾在这条明确标注为教学反事实的路线中实际承受重刑；另行核对并补足一斗。市场马上安静，卖家更谨慎，后来却更难听到报错与完整证言。这不是秦朝真实判例或本案可考的法律适用。
- **先回应损失**：在完整记录和可核对陈述具备时，可促成双方核对并补足一斗；故意仍待查。买主的损失先有回应，但不等于卖主承认故意。
- **补记续查**：始终可选。次日双方再到县署，卷宗保留量粮人的原说与更正；处理损失因此延迟，但依据更清楚。

前四个对话选择影响公开初稿、田禾的雨路陈述、阿叶是否能说明所见边界，以及量粮人的更正是否进入卷宗。这些状态决定处理意见是否可选，并改变人物后续对白和数日后的市场行动。最终的市口说明会影响别人是否知道怎样更正错误。玩家是年轻县吏，只提出意见；反事实路线的裁断由审案官吏承担。

## 史实与虚构

三张可选秦代资料卡援引睡虎地秦简《效律》《封诊式》《法律答问》，用于讨论计量核验、讯问记录和法律解释；《效律》不被当作这宗私人交易的直接法条。春秋子产铸刑书与战国重刑思想只在明确标注年代的独立复盘中出现。开场“查实故意短给后受重刑”的先例是教学虚构；田禾实际受刑的路线是教学反事实推演。两者都不意味着秦律规定“少一斗即重刑”。游戏没有给本案编造秦律条文、刑名或刑度，也不把无法证明故意写成已证明田禾无责。
